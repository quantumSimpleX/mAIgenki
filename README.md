# mAIgenki

A mobile-first health visualization app. Upload your medical PDFs and see your entire health history mapped across organ systems on an interactive anatomical diagram — scrollable through time.

Built with Expo (React Native), TypeScript, NativeWind, and OpenRouter.

## Getting started

```bash
npm install
npx expo start         # dev server
npx expo start --web   # browser
```

## Commands

```bash
npm run typecheck   # tsc --noEmit
npm test            # jest --coverage
npx expo lint       # ESLint
```

See `CLAUDE.md` for full architecture and `SPEC.md` for requirements.
